# LanDrop Android TV 接收指南

本文件描述当前原生应用。设计稿位于本地工作区同级的 `landrop-ui-design/`；兼容性目标与尚未完成的事项见 [TV-TODO](TV-TODO.md)。开发与验证见 [开发指南](development.md)。

## 启动与后台接收

图标直接打开 `MainActivity` 的接收状态页，显示设备名、状态和保存目录。默认不展示附近设备，也不读取文件或剪贴板。主要操作为“选择内容发送”，另有返回后台、记录和设置入口。

后台接收和开机自启默认开启。开机只启动前台服务，不打开 Activity。退出界面或划掉最近任务不会关闭已启用的接收服务；明确停止后，关闭状态保留到再次启用。接收暂停时，主页先提供“开启接收”，启用后再进行正常发送流程。

保持原有前台服务、通知和 CPU 唤醒锁管理；空闲不持有传输唤醒锁。普通 APK 无法保证绕过厂商自启动限制、强行停止或深度待机断网。

## 主动发送

流程为：文件／文件夹／剪贴板 → 内容摘要 → 附近设备 → 进度和结果。支持文件多选、查看和清空待发送内容、刷新附近设备，以及 Android 分享进入待发送页。

没有手动地址输入、收藏、独立设备校验或媒体／手写文本弹窗入口。媒体文件通过普通文件选择器发送；剪贴板仅在主动点击时读取。

优先系统文件选择器，其次系统内容选择器；缺少组件时使用现有内置文件浏览器。内置浏览器遵守存储授权，不申请所有文件访问权限。Android 10+ 缺少系统选择器且没有目录授权时，不能承诺浏览全部共享存储或 U 盘。文件夹选择仍依赖系统目录选择器；元数据保留所选根目录及子目录名，接收端按相对路径保存。空目录没有文件载荷，当前不传输。系统存储提供方和 U 盘行为仍需实机验收。

## 来件与传输结果

文件、文件夹内容和文本先展示来源及摘要，提供拒绝／接受；默认焦点在拒绝，返回键也拒绝。文本接受后才展示复制操作，不自动复制或打开链接。正常文本消息按 LocalSend `preview` 与 204 确认语义处理，不保存为文本文件。

待确认请求 60 秒过期，服务解决请求或超时后关闭待确认弹窗。当前 UI 不提供单次接收的部分选择、文件改名或临时更换目录，接受时按当前授权目录接收整个请求。

传输页显示进度、取消和当前任务结果。收到文件默认保存到 `Download/localsend/`；在设置选择其他目录后使用持久化授权目录。记录数据库版本 3 保留旧接收记录，并记录新的收发方向和结果；发送记录不保存本地文件 URI，详情中无路径时显示“—”。清空记录不删除实际文件。

## 设置与权限

设置仅保留后台接收、开机自启、电视悬浮提醒、语言、设备名、保存目录，以及版本和许可入口。“通用”和“接收”为同样式的无图标标题；行内图标在左、开关或值在右。

设备名通过确认／取消弹窗修改，空白名称不可保存；确认后在线服务重新广播，无需重启。固定蓝色，支持明暗主题及清晰的遥控焦点；不提供主题色、网络接口、加密或地址配置界面。历史偏好的运行时读取保留，不主动抹除已有设置。

电视悬浮确认需要用户在系统设置授权，首次授权后返回重新开启。悬浮提醒使用右侧确认面板；系统阻止悬浮时保留通知入口。Android 13+ 需通知授权；拒绝通知不等于允许后台弹窗。

没有新增定位、蓝牙、通讯录或所有文件访问权限。读取系统设备名失败时使用设备型号；网络、组播、启动广播和前台服务使用必要的声明权限。Android 9 及以下写公共下载目录需要传统存储授权。

## 当前兼容边界

LocalSend 路径、端口、组播及 JSON 身份字段保留。地址 URL 构造由共享 `DeviceEndpoint` 提供，继续服务自动注册与远端取消；移除的是无人调用的手动发送连接器。

本地接收监听仍为 HTTP，对端可以声明 HTTP 或 HTTPS；出站 HTTPS 使用客户端证书及证书指纹核验。首次使用证书身份会替代旧开发安装的随机 HTTP 标识，之后改名不更换证书。连接原版默认配置的代码已接入，实际双向互通仍未验收；不能据此宣称全面兼容。接收确认窗口为 60 秒，发送等待为 90 秒；待确认的无会话 ID 取消按发送地址匹配。摘要失败／重试和边界时序见 [TV-TODO](TV-TODO.md)。
